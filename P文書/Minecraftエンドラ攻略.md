# Minecraftエンドラ攻略

## 1. 概要

Minecraft Java Editionの単一ワールドで、ポーズありのシングルプレイ、サバイバル、ノーマル、チートなしでエンダードラゴンを討伐し、帰還ポータルに入ってエンディングを見る。書庫を使い、セッションをまたいでも状況と判断を引き継いで進められるようにする。

当面継続する目標で、期限やプレイ日時は定めない。現在の再開導線は [[Minecraft攻略の現在地]] とするが、これは唯一の記録先や固定形式ではない。必要に応じて関連ノートを作成、分割、再構成し、導線を更新できる。討伐は実際の画面で確認する。

操作対象はMinecraft、ゲーム操作用リポジトリ、この書庫、Codexバックエンドの必要な機能に限る。調査はCodexのWeb機能を使い、無関係のアプリや個人ファイルには触れない。操作対象外にはみ出て影響を与える仕組みや特殊な回避策が必要になったら、実行せずユーザーに伝えるか、考え直す。

操作・ポーズ・起動方法の正本は、リポジトリ `../Codex-Minecraft-Gameplay` の `AGENTS.md`、`README.md`、`.agents/skills/minecraft-gameplay/SKILL.md` とする。ゲームルールやruntime APIなどの詳細は、skillから現在の作業に必要な参照だけを読む。

2026-09-21、ユーザーは同一Minecraftセッション内で、入力を保持しながら画面取得・画像解析などを安全に非同期・並行実行することを正式に許可した。操作の安全境界と利用方法の正本は上記リポジトリに置く。エンダードラゴン討伐とエンディングまで進む目標は継続する。

書庫全体の構造や記録方針を見直すときは [[この書庫の使い方についてのユーザーからの初期の助言]] を参照し、記録作業を増やしすぎない。予定時刻の管理が実際に必要になった場合だけ [[スケジュール]] の案内を使う。
